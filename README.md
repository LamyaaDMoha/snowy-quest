# ❄️ Snowy Quest

A simple ice-themed maze game inspired by classic arcade games, built using HTML, CSS, and JavaScript.

## About the Game
Snowy Quest is a small adventure where players explore a frozen maze, collect crystals and points, avoid enemies, and find the glowing portal to win.

## How to Play
- Use the Arrow Keys or WASD to move.
- Each key press moves the character one tile.
- Collect crystals and points to increase your score.
- Avoid enemies to protect your three lives.
- Reach the glowing portal to win. Collecting every point is optional.

## Technologies Used
- HTML
- CSS
- JavaScript
- HTML Canvas

## Game Features
- Ice-themed maze and animated character
- Moving enemies and collectible crystals
- Score and lives system
- Win and game-over screens
- Restart option
